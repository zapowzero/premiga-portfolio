## Data projects

### Road accident analysis: US Accidents (Kaggle, 2016–2023) 📊
Two questions answered from a large real-world dataset: *Where do accidents happen?* and *Which road features are linked to high-impact accidents?*
- Loads only the columns needed from the full CSV and compares road-feature shares between high-impact (Severity 3–4) and low-impact (Severity 1–2) accidents
- Finding: junctions make up **40.6%** of road-feature flags in high-impact accidents but only **14.6%** in low-impact ones
- Each analysis has a one-page summary report with findings, recommendations and limitations

**Tech:** Python · pandas · NumPy · Matplotlib  →  [`zapow dataviz/`](zapow%20dataviz/)
